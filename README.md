# Habit — Habit Tracker

A focused habit-tracking web app built with HTML5, CSS3 and vanilla JavaScript.

## Features

- Daily habit tracking
- Daily, weekday and weekly frequencies
- Streak calculation
- Weekly consistency view
- Add, edit and delete habits
- LocalStorage persistence
- Responsive design
- No frameworks
- No build step

## Run

Open `index.html` directly in your browser or use VS Code Live Server.
